# Pokémon Encyclopedia & Discovery

## Project Description

My program will be an interactive Pokémon Encyclopedia that uses the PokéAPI to retrieve information about different Pokémon.

The user will be able to search for a Pokémon by entering its name or Pokédex number. The program will retrieve information from the API, including the Pokémon's name, ID, height, weight, types, abilities, and base stats.

In addition to searching for Pokémon, the program will allow users to compare two Pokémon based on their stats, including attack, defense, and speed. The program will calculate and display which Pokémon has the higher stats.

The goal of this project is to create an interactive Pokémon discovery experience using Java and JSON data from a Web API.

## API Information

**API:** PokéAPI

**Example API URL:**

https://pokeapi.co/api/v2/pokemon/pikachu

The Pokémon name or Pokédex number at the end of the URL will change depending on the user's search.
